# Web Development Projects

A collection of small learning exercises and web interface prototypes built with HTML, CSS, JavaScript and React.

## Selected examples
- [Weather App](./weather-app/README.md) - city search and weather display demo. Live API access is disabled until a secure server endpoint is configured.
- [Responsive Contact Layout](./responsive-contact/README.md) - Bootstrap layout exercise.
- [React Album](./react-album/README.md) - image gallery prototype.
- [Checkout List](./checkout-list-kanevice/README.md) - interactive cart calculation demo.

## Security
Never commit API keys, tokens, personal data or private documents. Keep local environment files out of Git. If a key was ever committed, revoke or rotate it at the provider; removing it from the current file does not invalidate it or erase historical copies.

## Status
This is a learning archive. Individual examples may need tests, accessibility work, and third-party asset/license review before production use.
